Sobre o projeto: # Sistema Socio Torcedor Corinthians
Com base nas disciplinas desenvolvidas criei um sistema de socio torcedor do time corinthias seguindo as orientações e necissades do programa. 

Funcionalidades Principais:
Sistema de cadastro de usúario;
Login de usuario;
Sistema de venda de ingresso simulado;
Listagem de socios logados;
Utilidades Extras: 
Contagem de compra de ingressos por socio; 
Integração da Lista salva em Json; 
Criação de um Ticket simulado pela compra;

Tecnologia Utilizada:
Sistema feito completamente e unicamente em Python. 
Frameworks: Hashlib e Json. 

Execução do projeto:
Para executar o projeto e somente necessário a linguaguem python (ver. utilizada para criação 3.14) e um interpretador ou até mesmo terminal (Vs code, Pycharm e etc).
